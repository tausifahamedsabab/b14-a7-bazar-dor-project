# বাজার দর | BazarDor

**BazarDor** is a Bangla-language market price web application that helps users explore everyday products and view current market prices in one place.

## Technologies Used

- **Next.js** — React framework for building the web application
- **React** — Component-based user interface
- **TypeScript** — Type-safe JavaScript
- **Tailwind CSS** — Responsive styling and UI design
- **Better Auth** — User authentication and account management
- **REST API** — Fetching product, category, and market price data

## Key Features

1. **Product Categories** — Browse everyday products by category, including rice, lentils, vegetables, fish, meat, oil, and spices.
2. **Live API Data** — Fetch product information and market prices from the BazarDor API.
3. **Price Sorting** — Sort products by default order, lowest price, or highest price.
4. **Price Change Indicators** — Identify products with increasing or decreasing prices.
5. **User Authentication and Profile Management** — Sign up, sign in, sign out, and manage account information using Better Auth.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tausifahamedsabab/b14-a7-bazar-dor-project
cd C:\projects\b14-a7-bazar-dor-project
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file and add the environment variables required by your Better Auth configuration.

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
